# Contributing to AION Clinical

Thank you for considering a contribution to AION Clinical.

## License of contributions

By submitting a contribution, you agree that your contribution may be used, modified, distributed and sublicensed by Iscad GmbH and the project maintainers under the same dual-license model as the project:

- European Union Public Licence v. 1.2 (`EUPL-1.2`); or
- a separate commercial license offered by Iscad GmbH.

Do not submit contributions unless you have the right to license them under these terms.

## Developer Certificate of Origin

Each commit should include a sign-off line:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use:

```bash
git commit -s
```

The sign-off means that you certify the Developer Certificate of Origin in `DCO.md`.

## Optional contributor agreement

For substantial contributions, the maintainers may request a signed contributor agreement. See `CLA.md` for the project template.

## Contribution rules

- Do not submit confidential, patient-identifying or third-party proprietary material.
- Do not submit code copied from incompatible licenses.
- Add or preserve SPDX headers where practical.
- Keep medical-device and clinical-use disclaimers intact.
- For changes affecting clinical semantics, interoperability behavior, validation or safety-relevant logic, include tests and documentation.

## Recommended file header

```text
SPDX-License-Identifier: EUPL-1.2 OR LicenseRef-Iscad-Commercial
```
