# Contributing to AION Clinical

Thank you for considering a contribution to AION Clinical.

## Licence of contributions

AION Clinical is **dual-licensed**: **AGPL-3.0-only OR Commercial** (ISCaD GmbH).

By submitting a contribution, you agree that your contribution may be used,
modified, distributed and sublicensed by ISCaD GmbH and the project maintainers
under the same dual-license model as the project:

- GNU Affero General Public License v3.0 only (`AGPL-3.0-only`); or
- a separate commercial license offered by ISCaD GmbH.

Do not submit contributions unless you have the right to license them under these terms.

### SPDX header for new files

```text
SPDX-FileCopyrightText: 2026 Friedhelm Matten / ISCaD GmbH
SPDX-License-Identifier: AGPL-3.0-only OR LicenseRef-ISCaD-Commercial
```

## Developer Certificate of Origin

Each commit should include a sign-off line:

```text
Signed-off-by: Your Name <your.email@example.com>
```

Use:

```bash
git commit -s
```

The sign-off means that you certify the Developer Certificate of Origin in `DCO.md`.

## Optional contributor agreement

For substantial contributions, the maintainers may request a signed contributor
agreement. See `CLA.md` for the project template.

## Contribution rules

- Do not submit confidential, patient-identifying or third-party proprietary material.
- Do not submit code copied from incompatible licences.
- Add or preserve SPDX headers where practical.
- Keep medical-device and clinical-use disclaimers intact.
- For changes affecting clinical semantics, interoperability behaviour,
  validation or safety-relevant logic, include tests and documentation.
