# Release Notes: 2.0.2

This release updates repository and package metadata for clearer dual licensing and publication hygiene.

## Changed

- Clarified dual-license wording: EUPL-1.2 or commercial license from Iscad GmbH.
- Added commercial license notice.
- Added NOTICE file.
- Added contribution rules, DCO and CLA template.
- Added SPDX file-header guidance.
- Updated PyPI metadata example to use modern license metadata and explicit license files.
- Replaced stale fixed latest-release wording with a PyPI release-history reference.

## No clinical certification claim

This release does not change the medical-device status of AION Clinical. The package remains a research, informatics and interoperability tool and is not a certified medical device under Regulation (EU) 2017/745 (MDR).
