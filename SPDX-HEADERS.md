# SPDX Header Templates

Use the following header in source files where practical.

## Python

```python
# SPDX-License-Identifier: AGPL-3.0-only OR LicenseRef-ISCaD-Commercial
# Copyright (c) ISCaD GmbH and contributors
```

## Markdown / text

```text
SPDX-License-Identifier: AGPL-3.0-only OR LicenseRef-ISCaD-Commercial
Copyright (c) ISCaD GmbH and contributors
```

## TOML

```toml
# SPDX-License-Identifier: AGPL-3.0-only OR LicenseRef-ISCaD-Commercial
# Copyright (c) ISCaD GmbH and contributors
```

## Important note

`LicenseRef-ISCaD-Commercial` is a local SPDX license reference for the separate commercial license path. It does not replace the commercial agreement itself.
